# Eva's Coordination Service

Professional starter website for Eva Johnston's event coordination business in the Quad Cities IA/IL area.

## Positioning

The first design direction is **warm romantic luxury**: wedding-forward, polished, and elegant, while still broad enough for private celebrations, community gatherings, and corporate events.

## Local preview

This is a dependency-free static site. Open `index.html` directly in a browser, or serve it locally:

```bash
python3 -m http.server 4173
```

Then open: <http://localhost:4173>

## Hosting options

Recommended low-maintenance options:

1. Netlify static site with Netlify Forms
2. Vercel static deployment
3. GitHub Pages from `main` branch root
